# Security Policy

## Supported Versions

Only the latest release of `turkce-denetim` receives active security updates and vulnerability patches.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability or potential exploit in `turkce-denetim`:

1. **Do not create a public issue.**
2. Report the vulnerability privately through [GitHub Security Advisories](https://github.com/YusufBeratZengin/turkce-denetim/security/advisories/new).
3. Include:
   - A clear description of the vulnerability.
   - Minimal reproduction steps, script, or sample text.
   - Potential impact and suggested remediations if known.

We aim to acknowledge reports within 48 hours and provide a timeline for fixes.
